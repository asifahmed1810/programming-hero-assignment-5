# Project Name: Donate Bangladesh

**Live Link:**  https://asifahmed1810.github.io/programming-hero-assignment-5/

FloodAid is a donation platform aimed at assisting communities affected by floods. The website connects donors with those in need by providing a transparent and efficient system for contributing to flood relief efforts.

## Technologies Used
- HTML 
- Tailwind CSS  
- JavaScript 
- React Toastify  

## Key Features
1. **Real-Time Donation Tracker**  
   Displays real-time updates on funds raised and allocation for transparency.  

2. **Secure Donation System**  
   Integrated secure payment gateways for hassle-free contributions.  

3. **Responsive and Inclusive Design**  
   Optimized for all devices to ensure accessibility for everyone.
